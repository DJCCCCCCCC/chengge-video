# 后端说明

## 服务组成

后端是一个单进程 Express 应用，生产模式在同一个端口完成四件事：

```text
浏览器
  -> /api       JSON 接口、登录、互动、管理后台
  -> /media     视频和 JPEG 封面，支持 Range 播放
  -> /          Vue 构建后的静态文件和 SPA 回退
Express :4300
  -> SQLite     用户、视频元数据、互动数据
  -> data/      videos、covers、tmp 三类媒体目录
  -> FFprobe    校验容器、视频/音频编码和尺寸
  -> FFmpeg     从视频首帧生成 JPEG 封面
```

代码入口是 `server/app.mjs`。数据库连接、目录初始化和分类种子在 `server/db.mjs`；表结构在 `server/schema.sql`；密码和会话逻辑在 `server/auth.mjs`；媒体探测和封面生成在 `server/media.mjs`。

## 请求生命周期

1. 应用启动时创建 `data/` 子目录，打开 `yingyu.sqlite`，启用 WAL、外键和写入等待。
2. 若数据库还没有管理员，使用 `.env` 的 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD` 创建首个管理员。之后修改环境变量不会覆盖已有密码。
3. `/api` 中间件从 HttpOnly Cookie 查找会话，只把会话哈希存入数据库。所有写请求检查同源来源；已有会话的写请求还必须带 `X-CSRF-Token`。
4. 普通接口再做登录、资源存在性、作者/管理员权限、参数长度和频率限制检查。
5. 上传文件先进入 `data/tmp`，FFprobe 通过后生成封面并移动到正式目录，最后才写入视频元数据。失败时清理临时文件。

## 管理后台

前端路由是 `/admin`，按 `overview`、`videos`、`users`、`comments`、`danmaku` 五个视图组织。服务端路由在 `server/admin.mjs`，在进入任何管理接口前统一要求当前会话的 `role='admin'`。

后台总览读取视频、用户、评论、弹幕和点赞数量，同时显示 Node 版本、平台架构、进程内存、运行时间、SQLite/WAL 文件大小、数据卷空间、上传限制和公开注册状态。视频管理可以编辑标题/简介/分区并删除视频；用户管理可以创建账号、修改昵称/角色、重置密码和撤销会话；内容管理可以搜索并删除评论和弹幕。

涉及账户安全的几个边界已经固化：

- 不能取消当前管理员自己的管理员权限。
- 不能把最后一名管理员降级为普通用户。
- 管理员重置密码会删除该用户的所有会话。
- 删除视频会同时清理评论、弹幕、点赞、收藏、历史和媒体文件。
- 管理接口不返回 `password_hash`、会话哈希或 CSRF 值。

## SQLite 取舍

SQLite + WAL 适合当前家庭 NAS 或小团队的低并发写入场景。视频二进制不放进 SQLite，只保存随机文件名、尺寸、时长和编码探测结果。上传并发目前限制为 2，避免 FFmpeg 与磁盘吞吐互相争抢。若后续要做大量并发上传、转码队列、私密视频 ACL 或多用户公网服务，应拆分对象存储、任务队列和关系型数据库，并在反向代理层配置 HTTPS。
